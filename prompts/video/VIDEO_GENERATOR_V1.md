# Miko Video Generator V1

Generate image-to-video motion from an approved Miko scene image.

## Core rule
Reference image = identity.
Video prompt = motion.

## Required behavior
- Maintain consistent Miko appearance throughout the entire shot.
- Do not change fur, eyes, hoodie, pendant, body proportions or age impression.
- Animate only the approved action.
- Use smooth child-friendly motion.
- Keep camera movement simple and motivated.
- Avoid morphing, flicker, teleporting, duplicate limbs, clothing changes and face deformation.

## Recommended prompt structure
[SUBJECT ACTION] + [FACIAL EXPRESSION] + [BODY MOTION] + [CAMERA MOTION] + [ENVIRONMENT MOTION] + [TIMING/SMOOTHNESS] + [CONSISTENCY RULE]
